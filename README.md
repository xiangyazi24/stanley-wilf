# stanley-wilf

A Lean 4 formalization project for the Stanley–Wilf growth-limit theorem,
organized around the symbolic method:

```text
sum/skew indecomposability
  -> closure of the avoidance class under one block operation
  -> unique component decomposition: C = SEQ(I)
  -> fixed-size concatenation is injective
  -> c(m+n) >= c(m)c(n)
  -> Fekete + the Marcus–Tardos exponential bound
  -> a finite limit of c(n)^(1/n).
```

**Status: initial formalization, not a completed Lean proof.** Source is written
without proof placeholders or project axioms. The authoring environment had no
Lean executable and could not download a toolchain; no Lean compilation or
kernel axiom audit has been performed. Successful source checks and finite
Python tests are not a substitute for Lean verification. See
[the precise status](docs/STATUS.md).

The mathematical paper proof is complete **using the already-proved
Marcus–Tardos theorem**. This is not a new proof of that theorem. In Lean its
exponential bound is an explicit input, not an asserted axiom or a disguised
unproved theorem.

## Dependencies

- Lean `v4.29.0`.
- mathlib `8a178386ffc0f5fef0b77738bb5449d50efeea95` (`v4.29.0`).
- [AnalyticCombinatorics](https://github.com/xiangyazi24/AnalyticCombinatorics)
  `3a426641ccfd0add82a82e169083ff97c8d03027`.

The existing library supplies `CombClass`, `CombClass.seq`, and
`CombClass.ogf_seq_mul`. We reuse its finite graded classes and its **formal**
power-series sequence theorem, rather than silently treating a formal identity
as an analytic convergence theorem.

The pinned library's dependency manifest was inspected. This new project's
`lake-manifest.json` must be generated by Lake, rather than fabricated without
a dependency-resolution run.

## Build and audit

With the pinned Lean toolchain available:

```sh
lake update
lake exe cache get
./scripts/check.sh
```

This runs source checks, finite regression tests, `lake build`, and the
`#print axioms` audit. A missing Lean executable is an error, never a pass.
Generated build logs are local and ignored by Git.
